# 3D models

The prototype intentionally does not vendor hundreds of Pokémon GLBs into this repository.

It uses the Pokémon 3D API asset repository/CDN for optimized models:

https://github.com/Pokemon-3D-api/assets

Current prototype examples:

- Pikachu: National Dex 25
- Charizard: National Dex 6
- Bulbasaur: National Dex 1

This keeps the Git repository lightweight while allowing the app to scale to a large catalog.

Before distributing a build, review the upstream project's asset/credit notice and remember that Pokémon character assets remain owned by their respective rights holders.
